# Gate Nexus Launcher

一款 Minecraft Java 版启动器，支持离线模式和正版登录。刚发布，可能还有一些 bug。

A Minecraft Java Edition launcher supporting both offline mode and official account login. Newly released, so there may be some bugs.

## 功能 / Features

- 离线模式 / Offline mode
- 正版登录 / Official account login
